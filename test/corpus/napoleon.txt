Multiword headings allow horizontal whitespace
==================

Keyword   Args :
  value: A value.
See	Also:
  Another function.

---

(document
  (keyword_args_section
    header: (section_header)
    (parameter
      name: (identifier)
      description: (description
        (text))))
  (see_also_section
    header: (section_header)
    (text)))

==================
Napoleon headings are case insensitive
==================

nOtEs:
  Ordinary prose.
KEYWORD ARGUMENTS:
  value: A value.

---

(document
  (notes_section
    header: (section_header)
    (text))
  (keyword_args_section
    header: (section_header)
    (parameter
      name: (identifier)
      description: (description
        (text)))))

==================
Prose sections end before adjacent sections
==================

Examples:
  Descriptive example.
Notes:
  First note.
  Second note.
Warning:
  Cautionary prose.
Warns:
  UserWarning: A structured warning.
Returns:
  A string formatted as key: value.

---

(document
  (examples_section
    header: (section_header)
    (text))
  (notes_section
    header: (section_header)
    (text)
    (text))
  (warning_section
    header: (section_header)
    (text))
  (warns_section
    header: (section_header)
    (exception
      name: (exception_name)
      description: (description
        (text))))
  (returns_section
    header: (section_header)
    (return_value
      description: (description
        (text)))))

==================
Known headings nested in prose stay prose
==================

Notes:
  A description containing a nested heading:
    Examples:
      An example description.
  More prose.
Todo:
  Finish the work.

---

(document
  (notes_section
    header: (section_header)
    (text)
    (text)
    (text)
    (text))
  (todo_section
    header: (section_header)
    (text)))

Unknown and inline headings stay prose

Custom Section:
  User-defined prose.

  (text)
